## Model lineage

newhall-rs implements a model with a long history:

1. Franklin Newhall's soil moisture regime model, originally implemented in
   COBOL.
2. The Van Wambeke BASIC reimplementation of the Newhall model. According to
   the jNSM project, these original sources are in the public domain due to
   age and lack of original licensing.
3. jNSM v1.6.1, a Java implementation derived from the Van Wambeke BASIC
   version, by Drew Waltman: <https://github.com/drww/newhall> (released under
   the New BSD license).
4. A modified jNSM v1.6.5 bundled with the jNSMR R package:
   <https://github.com/ncss-tech/jNSMR>.

We gratefully acknowledge the authors of each of these works.

## Use of upstream work

jNSM and jNSMR were used only as a behavioral reference and as a test oracle
to verify numerical parity (see `planning/AUDIT_JNSM.md`). The golden-master
test fixtures in `crates/newhall-core/tests/fixtures/` contain model inputs
and outputs generated by running jNSMR v0.3.1 on its bundled example data.
