## Notes
- **Facts discovered in Analysis:**
  - `terra` `1.9.51` `set.cats(x, layer, value, active = 1)` renames `names(x)[layer]` to `colnames(value)[2]` unless that column name is a reserved color/count name. Since `.regime_cat_df(levels)` in `r-pkg/R/categories.R` names column 2 `"category"`, `.attach_regime_cats()` must rename column 2 to the target layer name (`temperatureRegime`, `moistureRegime`, `regimeSubdivision1`, `regimeSubdivision2`) before calling `terra::set.cats()` so layer names remain intact.
  - `newhall_batch_phase4_rust()` in `r-pkg/src/rust/src/lib.rs` hardcodes `is_metric = true` and requires length-`n` slices for `o_thickness`, `bulk_density`, `quartz_frac`, `porosity`, `z_wt` and `12 * n` for `snow_flat`. `newhall_batch_phase4.SpatRaster()` should validate `unitSystem` via `.normalize_unit_system()` (erroring if non-metric) and extract optional Phase 4 raster layers when present or expand scalar fallbacks to `nrow(valid_chunk)`.
  - `newhall_batch_raw()` and `newhall_batch_phase4_raw()` are defined by sibling task `4.2.1` in `r-pkg/R/newhall.R` (not yet in this worktree).
  - `r-pkg/src/`, `r-pkg/R/newhall.R`, and `r-pkg/R/categories.R` must NOT be touched.
- **Risks:**
  - Leaving open `terra` read/write handles on error if `on.exit()` cleanup is not tracked with boolean flags (`read_open`, `write_open`) cleared after normal `writeStop()`/`readStop()`.
  - Partial `snowJan`..`snowDec` layer sets in Phase 4 rasters: validate either 0 or all 12 snow layers are present.
